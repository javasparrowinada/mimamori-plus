履歴: ↶ 戻る / ↷ 進むで直近の編集を取り消し/やり直し（最後に編集したカード単位）。 💾 保存はいつでも押せます（編集は自動でも保存されます）。⤺ 最初に戻すは強制リセットで全ての編集を破棄します（要確認）。
α 版機能: テキスト編集（フォント / 色 / サイズ / 装飾 / 配置）+ 点線編集 + 別画面で開く。 画像追加 / 自由配置 / 書き出し（HTML+CSS+画像zip）は次フェーズで追加予定。
